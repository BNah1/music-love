# Nhật ký agent

[English](README.md) | Tiếng Việt

Đây là hồ sơ vận hành của riêng project; lịch sử được ghi nối tiếp.

- `current/`: phân công role đang có hiệu lực.
- `phases/<phase>/tasks/`: mỗi task có một Markdown record chính thức.
- `reviews/` và `tests/` trong phase: bằng chứng review và test riêng biệt.
- Handover history ghi cùng task hoặc log phase, chỉ thêm lịch sử.
- `archive/`: giữ task và phase đã lưu trữ; không xóa bằng chứng.

Bản này hướng dẫn bằng tiếng Việt; tên file, trạng thái và lệnh giữ nguyên để dùng chung với bản tiếng Anh. Khi sửa quy trình, cập nhật cả hai bản.
