# Agent Entry Point

On the first session in a project, or when instructions changed, read `CONTROL.md`, the governance index and core governance files, `project_management/MASTER_PLAN.md`, and `.agent_logs/README.md`.

For assigned work, read `CONTROL.md`, the relevant live role file, the canonical task, its required context links, applicable rule modules and selected skill. Read the active phase plan when dependencies or exit criteria matter. Follow `governance/CONTEXT_WORKFLOW.md` for the exact loading order.

Project-specific instructions live in `governance/CODING_RULES.md` and project management documents. Do not silently override existing repository instructions; ask the Owner when they conflict.

Read applicable modules in `handle_rules/`. Available project skills live in `skills/`; read their instructions before using them. Governance and Owner controls determine authority; skills provide procedures.

Do not load unrelated tasks, evidence, archives, rule modules or skills by default. Repository-level instructions still apply even when a task does not link them.
