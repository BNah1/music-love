# Kỹ năng cho agent

[English](README.md) | Tiếng Việt

Đọc danh mục rồi chỉ mở SKILL.md cần cho task. Skill không cấp thêm quyền; governance và CONTROL.md quyết định quyền.

| Nhu cầu | Folder |
|---|---|
| Tiếp nhận repository | project-intake |
| PO, yêu cầu, task, lập lại kế hoạch | product-planning |
| Dev, triển khai | development |
| Review độc lập và phân loại findings | independent-review |
| Kế hoạch test và bằng chứng | verification |
| Thiết kế kiến trúc | architecture |
| UX cho web/mobile | ux-design |
| Hết quota hoặc tiếp tục session | handover-takeover |
| Điều phối và vòng sửa | delivery-coordination |
| Chuẩn bị đóng phase | phase-retrospective |
| Server/backend/web/mobile/data/CI | platform-delivery |

AGENTS.md dẫn agent đến các file này. Đăng ký skill tự động là tùy chọn và phải theo cơ chế công cụ hỗ trợ. Giữ thư mục này là source chính, tránh chỉnh độc lập các bản copy đã đăng ký. Nguồn tham khảo ghi trong BMAD_IMPORT.md.

Bản này hướng dẫn bằng tiếng Việt; tên file, trạng thái và lệnh giữ nguyên để dùng chung với bản tiếng Anh. Khi sửa quy trình, cập nhật cả hai bản.
