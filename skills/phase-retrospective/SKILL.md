# phase-retrospective

Read the project's AGENTS.md, CONTROL.md, applicable governance, and canonical task first. Follow Owner authority and current gates. Use project-root-relative artifact paths; update the existing task rather than creating a parallel registry. Load only relevant context. This skill is portable Markdown and requires no BMAD runtime.

Use Planner with review/test evidence from their actual actors. Check task outcomes, criteria coverage, unresolved findings, integration checks, review exceptions and deployment status where relevant. Record residual risks and follow-up tasks in the phase plan. Recommend closure or further work with evidence. Only Owner accepts and closes. Archive records only after authorized closure, preserving evidence and correcting links; keep a single editable canonical record.
