# Project Rule Modules

English | [Tiếng Việt](README.vi.md)

Add project-specific rules to the relevant folder. Read modules that apply to the task; an empty module adds no requirements.

| Folder | Purpose |
|---|---|
| assets/ | Asset sources, storage, formats, attribution |
| ui_ux/ | UI conventions, accessibility, design references |
| license/ | Approved licenses and dependency/asset restrictions |
| security/ | Project security requirements and secret handling |

Other subjects may be added as folders. Record Owner-approved exceptions in project_management/OWNER_DECISIONS.md. Conflicting rules require clarification; do not silently choose an exception.
