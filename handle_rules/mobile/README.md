# mobile rules

English | [Tiếng Việt](README.vi.md)

Platforms: Android and iOS. The app scans and plays local music files and is offline-first.

Permissions and platform behavior must be verified on-device when changed. Do not introduce cloud sync or remote playback as part of routine tasks.

Record references, commands, verification criteria and decision authority here. No project policy is preconfigured. Link this module from relevant tasks.
