# project-intake

Read existing repository instructions first. When this framework is already installed, also read CONTROL.md and applicable governance. A new project may not have a canonical task yet; create project configuration and planning records before the first task. Follow Owner authority, use project-root-relative paths and load only relevant context. This skill is portable Markdown and requires no BMAD runtime.

Inspect repository instructions and actual paths before proposing changes. Identify stack, boundaries, commands, existing plans, and current work. Configure governance/CODING_RULES.md, relevant handle_rules modules, and the Master Plan with verified facts; label unknowns. Apply CONTROL choices only as directed by Owner. Preserve existing files and merge instructions deliberately. Output a short installation/conflict report and the next ready task. For takeover use handover-takeover instead.
