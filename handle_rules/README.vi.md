# Các nhóm quy tắc riêng của project

[English](README.md) | Tiếng Việt

Thêm quy tắc vào folder tương ứng và chỉ đọc module liên quan đến task. Module trống không tự thêm yêu cầu.

| Folder | Nội dung |
|---|---|
| assets/ | Nguồn, định dạng, lưu trữ và ghi công tài nguyên |
| ui_ux/ | Thiết kế, trải nghiệm và khả năng tiếp cận |
| license/ | Giấy phép được chấp thuận và giới hạn sử dụng |
| security/ | Bảo mật và quản lý secrets |
| server/ | Môi trường, hạ tầng, vận hành |
| backend/ | API, dịch vụ, lưu trữ và tích hợp |
| web/ | Trình duyệt, rendering, hiệu năng |
| mobile/ | Thiết bị, nền tảng và phân phối ứng dụng |
| data/ | Schema, chất lượng và vòng đời dữ liệu |
| cicd/ | Pipeline, artifact, triển khai và rollback |

Có thể thêm folder theo nhu cầu. Ghi ngoại lệ Owner duyệt trong project_management/OWNER_DECISIONS.md. Khi quy tắc xung đột, làm rõ trước khi áp dụng ngoại lệ.

Bản này hướng dẫn bằng tiếng Việt; tên file, trạng thái và lệnh giữ nguyên để dùng chung với bản tiếng Anh. Khi sửa quy trình, cập nhật cả hai bản.
