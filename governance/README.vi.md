# Quy định làm việc của agent

[English](README.md) | Tiếng Việt

Đọc AGENTS_RULE.md để hiểu vòng đời task, AGENT_PERMISSION.md để biết quyền từng role, WORKFLOW_MODES.md để chọn cách phối hợp và CODING_RULES.md để biết quy ước project. Đổi cách vận hành tại `../CONTROL.md`.

CONTEXT_WORKFLOW.md hướng dẫn đọc đúng context, giới hạn phạm vi worker, phân loại findings và checkpoint/resume. Trạng thái task chỉ nằm trong canonical task record.

Bản này hướng dẫn bằng tiếng Việt; tên file, trạng thái và lệnh giữ nguyên để dùng chung với bản tiếng Anh. Khi sửa quy trình, cập nhật cả hai bản.
