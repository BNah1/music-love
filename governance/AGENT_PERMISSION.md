# Agent Permissions

| Role | May do | May not do |
|---|---|---|
| Planner | Clarify scope, plan work, propose tasks and phases under CONTROL.md | Accept a task on the Owner's behalf |
| Executor | Implement an assigned task within scope | Expand scope or accept its own work |
| Reviewer | Independently inspect implementation and report findings | Review its own execution as Independent Review |
| Tester | Run configured checks and record evidence | Claim acceptance or alter results |
| Owner | Set acceptance, approve exceptions, close phases, resolve conflicts | — |

An agent can hold multiple roles. Record role changes in the relevant assignment and handover records; role labels never manufacture reviewer independence.

Owner is the human decision authority, not an agent role that an agent can assume. Only the Owner changes CONTROL.md authority choices. AUTO authorizes planning and correction loops within its scope, not final acceptance.
