# Quy tắc dữ liệu

[English](README.md) | Tiếng Việt

Cấu hình schema, nguồn gốc dữ liệu, chất lượng, quyền riêng tư, thời gian lưu trữ và chạy lại có thể tái lập.

Chỉ cấu hình khi project cần. Ghi tài liệu tham chiếu, lệnh, tiêu chí kiểm chứng và quyền quyết định. Chưa có chính sách project được điền sẵn. Dẫn link module từ các task liên quan.

Bản này hướng dẫn bằng tiếng Việt; tên file, trạng thái và lệnh giữ nguyên để dùng chung với bản tiếng Anh. Khi sửa quy trình, cập nhật cả hai bản.
